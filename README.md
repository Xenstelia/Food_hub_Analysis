# FoodHub Project

## Overview
The FoodHub Project is designed to analyze customer orders and provide insights into purchasing patterns. This project utilizes data from the `foodhub_order.csv` file and analysis performed in the `IP_Project_Question_Notebook.ipynb`.

## Data Sources
1. **foodhub_order.csv**: Contains customer order data, including order IDs, product details, quantities, and timestamps.
2. **IP_Project_Question_Notebook.ipynb**: A Jupyter Notebook used for data analysis and visualization.

## Key Features
- Data cleaning and preprocessing.
- Exploratory data analysis (EDA) to uncover trends and patterns.
- Insights into customer behavior and product performance.

## How to Use
1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```bash
   cd foodhub_project
   ```
3. Open the Jupyter Notebook:
   ```bash
   jupyter notebook IP_Project_Question_Notebook.ipynb
   ```
4. Run the notebook cells to perform the analysis.

## Results
- Detailed analysis of order trends.
- Identification of top-selling products.
- Insights into peak order times and customer preferences.

## Requirements
- Python 3.x
- Pandas
- Matplotlib
- Jupyter Notebook
